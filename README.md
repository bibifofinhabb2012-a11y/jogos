# Jogos

## Meu Bebê

Jogo de cuidar de um bebê como se fosse de verdade, feito para jogar com leitor de tela (TalkBack, NVDA, JAWS, VoiceOver).

- `meu-bebe/` — app Android. O APK é gerado automaticamente a cada envio: aba **Actions**, execução mais recente de "Gerar APK do Meu Bebê", item **meu-bebe-apk**.
- `meu-bebe/web/meu-bebe.html` — versão para abrir no navegador do computador.
